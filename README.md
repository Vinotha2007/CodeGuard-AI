# CodeGuard AI 🚀

CodeGuard AI is an AI-powered code review assistant designed to help engineering teams improve software quality.

## Features

- Security vulnerability detection
- Hardcoded credential identification
- SQL Injection detection
- Performance bottleneck detection
- Infinite loop detection
- Code quality scoring
- AI review summary generation

## Tech Stack

- Python
- Gradio

## Problem Statement

AI-Powered Code Review Assistant for Engineering Teams

## How to Run

```bash
pip install gradio
python app.py
```
